grid_tools

Introduction

The grid_tools include:

  • filter_topo.F90 - filter topography
  • global_equiv_resol.f90 - compute the equivalent global resolution of a regional grid
  • regional_esg_grid.f90 - create regional extended Schmidt gnomonic grids
  • shave_nc.F90 - shave down domains of FV3 files

This document is part of the UFS_UTILS documentation.

The grid_tools programs are part of the UFS_UTILS project.
